# Generatore SQL PACS — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** pagina «Generatore SQL» sotto Conoscenza: il tecnico chiede in italiano, un lavoratore in coda chiama Ollama e restituisce la query Oracle; notifica a risposta pronta; giudizio del tecnico; revisione del superuser.

**Architecture:** nuova app Django `text2sql` con il modello `Text2SqlRequest`. In `engine.py` va la logica del prototipo `/home/fede/text2sql-test/app/text2sql.py`, senza il server HTTP. Un comando `text2sql_worker` gira in un nuovo servizio compose. Frontend: pagina variante **A · Elenco e risposta** dell'anteprima `design-previews/sql-base.html` (`shared/sql.js`, `shared/sql.css`).

**Tech Stack:** Django 5 + DRF, pytest; React 19 + TS + MUI, vitest.

**Spec:** `docs/superpowers/specs/2026-11-20-text2sql-design.md`

## Global Constraints

- Permesso `text2sql.use_text2sql` «Usa il generatore SQL PACS». Revisione solo per il superuser.
- Modulo spegnibile `text2sql` (label «Generatore SQL»), segmento API `text2sql`, tipo di notifica `text2sql_ready`.
- Barriera `IsInternalOrPortalDedicatedApp` sul viewset.
- Domanda: obbligatoria, massimo 2000 caratteri.
- Variabili d'ambiente: `OLLAMA_URL` (vuota = non configurato), `T2S_MODEL=qwen2.5-coder:7b`, `T2S_NUM_CTX=16384`, `T2S_NUM_THREAD=0`, `T2S_TIMEOUT=900`, `T2S_ORACLE_VERSION=12`, `T2S_NUM_ESEMPI=6`, `T2S_MAX_SCHEMA_TOKENS=10000`.
- Tipi della risposta: `read` | `write` | `impossible` (dal prototipo READ / WRITE / NESSUNA).
- «Copia come esempio» usa il formato di `esempi_query.md`: ``### Domanda: <domanda>\n```sql\n<query>\n```\n``.
- Archie non esegue mai le query e non si collega al PACS.
- Migrazioni solo nuove. Baseline: lint 5, vitest 271, pytest 1037 (più i nuovi test).

## Review Focus

1. Un tecnico chiede il dettaglio, o manda un giudizio, su una domanda di un altro → 404. → test Task 1.
2. Il lavoratore viene riavviato con una domanda `running` → torna `queued` all'avvio. → test Task 3.
3. Ollama non raggiungibile o modello mancante → domanda `error` con un messaggio leggibile, notifica «non riuscita». → test Task 3.
4. Senza `OLLAMA_URL`, il POST risponde 503 «Generatore non configurato» e non mette niente in coda. → test Task 1.
5. Il comando `refresh_notifications` non cancella le notifiche `text2sql_ready`. → test Task 3.

**Interfaces — Produces:**
- `Text2SqlRequest`: `user` (FK, CASCADE); `question` (TextField); `status` (`queued`|`running`|`done`|`error`, default `queued`); `sql` (TextField, blank); `kind` (`read`|`write`|`impossible`|""); `warnings` (JSONField, default list); `seconds` (FloatField, null); `error` (TextField, blank); `created_at`, `started_at`, `finished_at`; `feedback` (`ok`|`ko`|""); `corrected_sql`, `feedback_note` (TextField, blank); `feedback_at`, `reviewed_at` (DateTimeField, null). `Meta.permissions = [("use_text2sql", "Usa il generatore SQL PACS")]`, ordering `-created_at`, indici su (`status`, `created_at`) e (`user`, `-created_at`).
- API `/api/text2sql/`:
  - list, create, retrieve e destroy sulle proprie domande;

  - `POST {id}/reviewed/` (solo superuser) con `{reviewed: bool}`.
- Il serializer espone anche `user_full_name` e `example_markdown` (solo nelle righe di review).
